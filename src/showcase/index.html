Klear — Lottie Asset Showcase

All animations are rendered from assets/lottie/*.json (brand palette: primary #0E7490, accent #22D3EE).

How to run: serve this folder's parent (src/) over HTTP, e.g. cd src && python -m http.server 8000 then open http://localhost:8000/showcase/index.html.

Animations are loaded from ../assets/lottie/<name>.json relative to this page, so they stay in sync with the app's bundled assets.
